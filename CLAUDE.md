# zoostr - project rules

## Workflow (IMPORTANT)
- **Direct-to-main. NO branch PRs.** This is Zaal's solo, pre-launch repo. Commit straight to `main`.
  Do NOT open a branch + PR for every small change - that piled up 13 draft PRs. Reserve a PR only for
  something genuinely risky or that needs a second set of eyes. Ceremony off; ship fast.

## Tokenomics
- Tokenomics are **OPEN and being crowdsourced.** Do NOT state fixed split numbers anywhere.
  Leave the splits as variables (X / Y / Z) and invite suggestions. Ignore any prior specific numbers.
